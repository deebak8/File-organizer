📌 Overview

The Automated File Organizer is a Python script designed to automatically sort and organize downloaded files into specific folders based on their file extensions. It helps keep your Downloads or any target directory clean by categorizing files such as images, videos, documents, audio files, and archives into their respective folders.

This project is ideal for anyone who frequently downloads multiple file types and wants an automated way to maintain an organized file system.

✨ Features

🔍 Automatic file detection based on extension

📂 Moves files to predefined folders (Images, Documents, Videos, Music, Archives, etc.)

⚙️ Customizable extension-to-folder mapping

🏗️ Creates target directories automatically if missing

🛡️ Handles duplicate filenames safely

🔁 Optional scheduling for background automation

🚀 Keeps your system clean and clutter-free# File-organizer
